## 2. 已确认的链条（与你的判断一致）

用日志首帧状态复现，**实飞的 `a_h=+34.4`，而我的模拟给 `a_h=-38.2`** ——
**水平符号相反**，说明本机在轨迹的**另一侧**，PD 项压过了 `u_i`：

```
target_a[1] = u_i[1] + (v_i-vel)[1]·0.8 + (x_i-error)[1]·0.5
            = -38.2  +  PD
若结果 = +34.4  ⇒  PD[1] = +72
⇒ (x_i - error)[1] ≈ +144  ⇒ 位置误差量级已与轨迹指令相当
```

**当位置误差与 `u_i` 同量级时**：
- `target_a[0]` 会被压成负数
- `conic_clamp` 走 `a_ver<0 → a_ver=0 → cap_hor=0`
- 返回纯竖直 `[min_mag, 0, 0]` ⇒ **`a_cmd_h=0`、`thr=0.05`** ⇒ 完全不跟踪

**⇒ 你的提议（降低交接速度）直接针对这个链条**：
速度低 → `dist` 小 → `(x_i-error)` 小 → PD 不再压过 `u_i`。
