## 2. 改动 1：倾角上限统一到 35°

### 2.1 问题

求解器锥 85→5°，控制器上限 `clamp(alt/3, 5, 35)` ⇒
**规划以为自己能倾 85°，控制器只允许 35°**。规划用掉的自由度兑现不了。

### 2.2 做法

```python
PCS_START_CAP_DEG = 35.0     # = 控制器 TILT_CAP_HI
```

### 2.3 ✅ 安全性验证（这一步发现了一个真风险）

**收窄起点锥会削弱"用大倾角消横速"的能力**，故先扫了入口包络：

```
    vh      锥85                        锥35
    10     18/20/24 ok                 18/20/24 ok        <- 相同
    40     18/20/24 ok                 18/20/24 ok        <- 相同
    80     tf=24 ok(35deg)             全部 infeasible    <- 差异！
   120     全 infeasible               全 infeasible
```

**⇒ vh≈80 时 35° 锥会让 P4 无解。而 P4 无解 ⇒ 无规划 ⇒ 停在 hold ⇒ 坠毁。**

**为什么仍可接受**：kOS 交班门要求 `vh < vh_gate = 10 m/s`（已核对
`boot/B1040-9.ks:249`），故日常飞不到该区域。

**但已加兜底**（kRPC 侧兜底门只查 `vmag<120`，vh 可达 ~89）：
35° 无解时用 **cvxpy 路径以 85° 重试**（codegen 改不了锥角）。
慢（~2 s）但只在异常工况触发，好过没有规划。

## 3. 改动 2：末段抬高 5 米

### 3.1 问题

规划的"速度归零点"在 `x[0]=0 ⟺ alt=TARGET_ALT`，而停机判据是
`alt <= TARGET_ALT+1` —— **两者几乎重合**，载具在规划刹停前就触地，
落地垂速 −1.6 ~ −10.8 m/s。

### 3.2 做法

```python
TERM_CLEARANCE = 5.0
TERM_DESCENT_VZ = 2.0
```

1. 交给求解器前 `h -= CLEAR`；取回后 `plan['x'][0,:] += CLEAR`
   ⇒ 规划末节点落在 `alt = TARGET_ALT + 5`，**跟踪坐标系不变**
2. **配套末段下降律**（必须）：`h < CLEAR` 时不再跟规划竖直剖面，
   改为满刹车到 `TERM_DESCENT_VZ`

### 3.3 ⚠️ 第一版末段律写错了，实测暴露

初版写成弱 P 环 `a_up = G0 + K_VEL*(vz_tgt - vz)`，实测：

```
  进入末段时 vz 已 -10.4
  弱 P 环给出 a_up = 16.5   而物理需要 20.3
  => 落地 vz = -12.20  （比不用末段律还差！）
```

**修法**：末段没有"留余量"的必要，直接命令**满刹车**
（`a_up_raw = +inf`，由 `min(_a_up_raw, _a_ver_need)` 夹住）：

```
  修后:  a_up = 20.31 = a_ver_need
  落地 vz = -2.67  ->  回归到 -2.02 ~ -2.09
```

**验证（改动 2 生效的直接证据）**：

```
plan end (after +CLEAR shift): alt=22.00 m   (target 17.0 + 5.0)
  plan_vz at end = 0.00   plan_vh at end = 0.00
  => 零速点现在位于触地上方 5.0 m
```

## 4. 改动 3：把姿态动力学写进规划

### 4.1 问题

节点 0 推力被强制竖直（倾角恒 0），节点 1 可立刻倾斜。
实测节点 0→1 需要 **21~213 deg/s**，物理上限约 **36 deg/s**。

### 4.2 做法（关键设计）

锥角是推力的**硬上界**，且节点 0 倾角恒为 0，故：

```
ang(n) = min( cap(n), n * PCS_SLEW_DEG_PER_NODE )
```

⇒ 规划自己的倾角必然满足 `tilt(n) <= n*SLEW`
⇒ `tilt(n+1)-tilt(n) <= SLEW` —— **这就是角速率限制，且是凸的**。

**为什么不用 `omega*tf`**：`tf` 是 cvxpy Parameter，
`omega*tf*frac` 是**参数乘积 ⇒ 非凸**，cvxpygen 无法生成。
逐节点常数形式避开了这一点。

**⚠️ 基准必须是 0**（初版写成 `pcs_end + n*slew`，无效）：
节点 0 倾角恒为 0，若 n=0 时锥角已是 5°，节点 1 仍能跳到 5+SLEW。

### 4.3 验证

```
  无斜率限制: 峰值倾角 7.8~11.4，最大倾角速率 22.6~48.7 deg/s
  SLEW=8.0  : 峰值倾角 7.6~12.1，最大倾角速率 21.4~35.1 deg/s  <- 落入物理上限
  且全部工况仍 optimal（可行性未损失）
```

## 5. 改动 4：检查质量闸门

### 5.1 发现：阈值与锥上限不自洽

codegen 重生时直接打印出证据：

```
[gate] 探测 16 次未找到峰值倾角 <= 20.0 deg 的可行规划，
       退回第一个可行 tf=11.75（其峰值倾角 35.0 deg）
```

**闸门拒绝了一切、空探 16 次后【退回最小时间解】** —— 恰是它想避免的结果。

原因：锥上限定为 35° 后，规划倾角**按构造**最多只能到 35°，
"退化解 57~84°"这一档**不可能再出现**；而阈值仍是 20 ⇒ 永不满足。

### 5.2 做法

```python
_PLAN_TILT_MAX_DEG = 35.0   # = PCS_START_CAP_DEG，两者必须一致
```

并加**加载时断言**（两常量分处文件不同位置，容易漂移）：

```python
assert abs(_PLAN_TILT_MAX_DEG - PCS_START_CAP_DEG) < 1e-09, \
    '闸门阈值必须等于锥角上限：否则闸门会拒绝一切规划并退回最小时间解'
```

### 5.3 验证

```
  trial    thresh      tf   peak tilt
  164053       20    18.25    13.09
  164053       35    18.25    13.09       <- 三档完全相同
  164053       89    18.25    13.09
  ...（六趟全部一致）
```

⇒ 锥角上限已承担"约束姿态"职责，闸门不再需要额外收紧。
**解算耗时 0.52 s → 0.14 s**（不再空探 16 次）。
