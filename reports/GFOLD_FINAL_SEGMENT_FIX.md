## 1. 本次故障：final 段油门被覆盖成 100%

### 1.1 现象（日志帧 44 → 45）

| 量 | 帧 44 (t=8.694) | 帧 45 (t=8.854) |
|---|---|---|
| `thr_cmd` | **0.050** | **1.000** |
| `a_cmd_mag` | 2.76 | **55.20** |
| `alt` | 238.1 | 226.3 |
| `vz` | −73.21 | −74.11 |

随后 `vz` 从 −74.11 一路升到 **+11.76**，`alt` 从 186 m **回升**到 187 m
—— **火箭满油门往上飞，再也没落下来**。

### 1.2 与 final 段进入判据精确吻合

final 段判据（`gfold_land.py:2129-2130`）：
```
|error[1:3]| < FINAL_RADIUS(20)  and  |error[0]| < FINAL_HEIGHT(200)
```

| 帧 | above_pad | dist_hz | <200? | <20? | thr |
|---|---|---|---|---|---|
| 44 | 201.3 | 4.76 | **False** | True | 0.050 |
| 45 | **189.5** | 4.68 | **True** | True | **1.000** |

**帧 45 是第一个同时满足两个条件的帧，也正是油门跳变的那一帧。**
⇒ 确认 `nav_mode` 在此切到 `final`。

**旁证**：`a_cmd_mag / (T/m) = 0.9402`（恒定），而 final 段
`target_a = td * a_cap`（单位向量乘 a_cap）⇒ 该比值恒定，与实测一致。

### 1.3 根因：`apply()` 覆盖了本段算出的油门

`gfold_land.py` final 段：

```
2147-2154:  计算自杀点火油门 thr  （est_h / est_h_low / frac / lerp）
2155:       self.v.control.throttle = thr
2156:       self.thr_cmd = thr
   ...
2182:       target_a = td * a_cap          <-- 幅值 = a_cap
2187:       self.apply(target_a, target_direction, game_dt)
```

而 `apply()` 内部（1556-1561）：

```
mag = ||target_a||                = a_cap
throttle = mag / a_cap            = 1.0        <-- 恒等于 1
self.v.control.throttle = throttle             <-- 覆盖掉 2155 行
self.thr_cmd = throttle
```

⇒ **2147-2156 行算得再对，也在同一帧被 2187 行覆盖成 1.0，成为死代码。**
⇒ **final 段实际上一直在满油门运行，与自杀点火律完全无关。**

### 1.4 参考仓库为什么没有这个问题

`dev/gfold/demo3_gfold.py`：

| 行 | 内容 |
|---|---|
| 405 | `vessel.control.throttle = target_throttle` ← 属于 **gfold 分支** |
| 413-427 | final 分支 **只算 `target_direction`，不写油门** |

参考仓库的 final 分支**不调用任何写油门的函数**。本移植把
`self.apply()` 加进了 final 分支，才引入这个覆盖。

### 1.5 不是能量问题（已核）

进入 final 时 alt=226.3、vz=−74.11、mass≈153 t：

```
a_cap = 58.7, a_net_max = 48.9 m/s^2
满推力停车距离 = 74.11^2/(2*48.9) = 56.0 m
可用高度       = 189.5 m
=> 高度是够的（余量 133 m）
```

**物理上完全能停住，是控制律的油门被覆盖才失控。**

## 2. 修复

`gfold_land.py` line 2210：

```diff
- target_a = td * a_cap
+ target_a = td * thr * a_cap
```

让 `target_a` 的**幅值**等于本段算出的 `thr`，这样 `apply()` 复算的
`|target_a|/a_cap` 恰好还原 `thr`。姿态方向仍用 `td`，语义与参考仓库一致。

### 修复验证（离线仿真，从真实入口状态出发）

| | 步 0 | 步 8 | 终态 |
|---|---|---|---|
| **修复前** | alt 215.7 vz −66.3 | alt 176.4 vz **−2.7** | vz **+659**，**未触地** |
| **修复后** | alt 214.3 vz −75.2 | alt 114.8 vz −72.9 | **alt 36.5 vz −2.01，触地** |

修复前的仿真**精确复现了日志现象**（`vz` 由负转正、火箭上飞）；
修复后正常触地（`vz=−2.01`，符合 `term_v=2.0` 指标）。
