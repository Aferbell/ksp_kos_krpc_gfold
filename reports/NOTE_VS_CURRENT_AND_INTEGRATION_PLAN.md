# note.md 控制 vs 现行代码：区别、可行性、整合方案

> 输入：`note.md`（根目录，一维双环演示：外环位置/速度反馈 + 内环加加速度追踪）

## 0. 一句话结论

**note.md 的外环与现行代码【已经是同一个东西】；真正的差别全在【内环】。**

现行内环限的是"倾角速率"（且用**跟踪判据**，比物理允许值低 **5.1 倍**），
note.md 限的是"加速度的加加速度"。**"只保留 tilt-first、把旧律整合进来"这件事，
本质上是把内环从"限倾角速率"改成"限 a_h 的加加速度"，并让竖直通道脱离旧律。**

可行性：**高**，且改动集中在 `track()` 的 ③~⑨ 段，
**不需要动 G-FOLD 规划、不需要动姿态 PID、不需要动 apply()**。

## 1. 外环：两者同形（这是关键认识）

### note.md 第 7 节扩展 1 已经把外环写全了

```
a_des = x_dd - kp*(x - x_d) - kd*(v - v_d)
```

### 现行代码（2857 行）

```python
target_a = u_i + (v_i - vel)*K_VEL + (x_i - error)*K_POS
```

**逐项对应**：

| note.md | 现行代码 | 含义 |
|---|---|---|
| `x_dd` | `u_i` | 参考点自身加速度（前馈） |
| `x_d` | `x_i` | 参考位置 |
| `v_d` | `v_i` | 参考速度 |
| `x - x_d` | `error - x_i` = `-_dp` | 位置误差（符号相反，等价） |
| `v - v_d` | `vel - v_i` = `-_dve` | 速度误差（同上） |
| `kp, kd` | `K_POS, K_VEL` | 位置/速度增益 |
| `clip(·, ±a_max)` | `conic_clamp(·)` | 幅值/方向限幅 |

代入 `x = -dp, v = dve`（"误差趋于 0"的口径）：
```
-kp*x - kd*v = kp*dp + kd*dve
```
⇒ **与现行的候选A（3298 行 `_ah_vec = u_h + kv*_dve + kp*_dp`）同形。**

> **所以"两条通道并行"这个说法要修正**：不是两套**外环**，而是
> **同一个外环的输出去驱动了两个不同的下游**：
> - 旧律下游：直接把 `target_a` 当加速度矢量 → 反算倾角（无限幅无限速）
> - tilt-first 下游：`|_ah_vec| → atan2 → 倾角 → 限幅限速 → 再反算 a_h`

## 2. 内环：这是真正的差别

### 2.1 结构对比

| | note.md | 现行 tilt-first |
|---|---|---|
| **内环状态量** | `a`（加速度） | `θ`（倾角） |
| **被限的物理量** | `j = d(a)/dt`（加加速度） | `dθ/dt`（角速率） |
| **限法** | `j = clip((a_des-a)/dt, ±j_max)`<br>`a_next = clip(a+j·dt, ±a_max)` | `θ_cmd = θ_prev + clip(θ_des-θ_prev, ±slew·dt)` |
| **到 a_h 的映射** | 恒等（状态就是 a） | `a_h = a_up·tan(θ)`（**非线性**） |
| **三量归零** | x, v, a 同时 → 0 | 倾角、a_h 由 θ 导出 |

### 2.2 "限倾角速率" ≠ "限加加速度"

由 `a_h = a_up·tan(θ)`：

```
d(a_h)/dt = a_up · sec²(θ) · dθ/dt
```

两个都会漂移：

```
sec²(tilt_cmd)  : p10=1.037  p50=1.154  p90=1.351  max=1.490
a_up (=av_up)   : p10=5.703  p50=9.071  p90=22.560
```

⇒ 同样的 `slew`，在高倾角/高油门时给出的等效 `j` 可以差好几倍。
**note.md 的内环直接作用于被控量 `a_h`，绕过了这个非线性。**

## 3. 最重要的发现：现行限速用的是"跟踪判据"，比物理允许低 5.1 倍

现行代码里有**两个性质不同的倾角速率限制**：

| | 公式 | 性质 | 实测 |
|---|---|---|---|
| **(a)** `_limit_ref_slew` | `sqrt(2·α·REF_SLEW_HEADROOM_DEG)`，clamp[8,45] | **物理判据**（加速到 slew 再同等减速停住，总角行程=45°） | p50=**34.6** deg/s |
| **(b)** `tilt_cmd` 速率限幅 | `TILT_SLEW_LAG_DEG·wn`，clamp[5,14] | **跟踪判据**（允许滞后 ~10°） | p50=**6.8** deg/s |

而 **实际约束 `tilt_cmd` 的是 (b)**：

```
物理/跟踪 比值 : p10=4.62  p50=5.08  p90=5.08   ← 稳定低 5.1 倍
```

### 这解释了之前反复出现的"需求快于限速"

```
需求变化率 |d(tf_corr)/dt|  : p50=11.8  p90=25.7  max=148.6 deg/s
实际限速 tf_slew_allow      : p50= 6.8  p90= 9.7   max= 10.7 deg/s
=> 63.9% 的帧需求变化快于允许上限
```

**改用 note.md 的内环 = 把判据从 (b) 换到 (a) 的物理口径**，这是有原则依据的改动，
而不是又一次拍参数。

### 换算到 a_h 通道的 j_max

```
j = av_up · sec²(θ) · slew
  (b) 跟踪判据:  p50 =  1.33 m/s³
  (a) 物理判据:  p50 =  6.76 m/s³   ← 高 5.1 倍
```

且 `α` 随油门变化 ⇒ **j_max 必须在线由 α 导出**：

```
j_max(α, θ) = av_up · sec²(θ) · sqrt(2·α·REF_SLEW_HEADROOM_DEG)
```

这与现行 `TILT_SLEW_ADAPT_ENABLE` 的动机一致，**只是判据从"跟踪"换成"物理"**。

## 5. 竖直通道：旧律"整合"的实际含义

**这是"整合旧律"最实质的一件事。** 现在竖直通道**不是规划的**：

```
av_up = _amag · cos(θ)          # 3565 行
其中 _amag = |conic_clamp(target_a)|，而 target_a 是 2857 行的【旧律 PD 向量】
```

实测：

```
av_up / av_plan : p10=0.519  p50=0.920  p90=1.719  max=2.799
```

**即竖直指令绕了一圈，又落回旧律 PD 的幅值上**——这正是我上一轮发现的
"往返污染"（`a_cmd_h == a_cmd_mag·sin(tilt_cmd)`，偏差 max 0.0026）。

**整合方式**：竖直不再从 `|target_a|` 投影，而是**直接算竖直 PD**：

```
a_up = u_i[0] + K_VEL·(v_i[0]-vel[0]) + K_POS·(x_i[0]-error[0])
```
再经 `conic_clamp` 的竖直保底/封顶（保留 `min_mag`、`AVER_FLOOR`、`a_ver_need` 逻辑）。

这样 `av_up/av_plan` 会趋于 1，**旧律被吸收进 tilt-first 的两个标量通道**
（水平 → `_ah_vec` 的模与方位；竖直 → `a_up`），而不是作为一条并行矢量通道。

## 6. 现行 `target_a` / `target_a_` 的命运

整合后各量的去处：

| 现有量 | 整合后 |
|---|---|
| `target_a`（2857 旧律 PD 向量） | **保留为外环**，但只用来取 `_ah_vec`（水平）与 `a_up`（竖直）两个标量，**不再整体进 conic_clamp** |
| `target_a_`（前瞻向量，3095） | 同上；`_limit_ref_slew` 仍然需要它 |
| `_amag = |target_a|`（3563） | **删除**（污染的来源） |
| `_a_up_old = _amag·cos(θ)`（3565） | 换成**竖直 PD** |
| `_a_h_new = _a_up_new·tan(_tilt_cmd)`（3612） | **换成 `a_h = a_h_cmd`（内环状态量）** |
| `apply()` | **完全不动**（仍只用 `|target_a|` 与 `target_direction`） |
| `conic_clamp` | 竖直部分保留；水平部分由 `_tcap` 夹限替代 |

## 7. 整合方案（建议分三步，每步可独立验证）

### 第 1 步：竖直通道脱离旧律（**独立收益，先做**）

- 3563-3565 行：`_amag`/`_a_up_old` → 直接竖直 PD
- 验证：`av_up/av_plan` 应趋于 1（当前 p50=0.92、p90=1.72）
- 风险：**低**（竖直行为变化可观察，且 `a_ver_need` 封顶仍在）
- 依据：§5

### 第 2 步：内环改为限加加速度（note.md 的核心）

- 3480-3484 行：`θ` 的速率限幅 → `a_h` 的加加速度限幅
- `j_max = av_up·sec²(θ)·sqrt(2·α·REF_SLEW_HEADROOM_DEG)`，加 `j_min` 下限
- 状态量从 `tf_tilt_prev` 换成 `a_h_state`
- 验证：`|d(a_h)/dt|` 不应再被 `slew_allow` 压制（当前 `j_track` p50=1.33）
- 风险：**中**（相位裕度会变，因为内环变快）
- 依据：§2/§3/§4

### 第 3 步：口径闭环（消掉 A=av_up/a_up_est）

- 前向 `_tcorr = atan2(|_ah_vec|, a_up_actual)`，与后向同一个 `a_up`
- **必须在第 1、2 步之后做**
- 依据：上一轮 diag50/51 已证 —— **单独做会被 A─B 抵消关系破坏**
  （`corr(A,B)=-0.461`，中位 −21%、p90 +46%）

### 必须先确认的设计取舍

- **阻尼比**：note.md 要过阻尼（`kd > 2√kp` ⇔ `zeta>1`，实测其参考参数 zeta=1.265）；
  现行候选A 恒为 `zeta=0.816`（欠阻尼，为相位裕度取的）。
  整合后取哪个？**建议保持 0.816 或略高**（0.9~1.0），因为
  相位裕度仍是紧约束（实测 2 阶 `PM(T=4)=-65°`，`PM=0` 需 T=10.79）。
- **低空倾角上限 `TILT_CAP_LO=5°`**：内环变快后，`a_h` 上限仍受 `a_up·tan(cap)` 限死。
  本趟实测：末段 11 帧只有 **1 帧**可行；若放到 35° 则 **11/11 可行**。

## 8. 已知局限（必须说明）

1. **仿真为 1D 归约**：日志的 `dp`/`dve` 只有**模长 + 余弦**，没有分量，
   所以 diag60/61 是在"误差方向"上做的一维重放。
   **真实 3D 行为（尤其方位角）未被验证。**
2. **未含姿态环动力学**：`tau_att=0.9 s` 是一阶近似，
   真实是 2 阶且 `zeta=0.366`（欠阻尼，会振铃）。
3. **未含 conic_clamp 与竖直耦合**：第 1 步会改变 `a_up`，进而改变 `a_h` 上限。
4. **`j_max` 的物理导出未被实飞验证**：只做了量级交叉检查（§4）。

**建议**：先做第 1 步（低风险、独立收益），再为第 2 步补**矢量日志列**
（`dp_n/dp_e/dve_n/dve_e`），把 1D 局限消掉后再上机。
