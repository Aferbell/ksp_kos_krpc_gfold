## 1. 基线 v8 的段1 是错的（已确证）

旧律：`a_v = -6·h_aim/T² − 2(−term_v + 2·vz)/T`

代入真实剖面各点的实际 a_v：

| h_aim | vz | T | a_v (v8) |
|---|---|---|---|
| 12321 | −656 | 30.8 | **7.5** |
| 8000 | −550 | 24.9 | **11.0** |
| 4000 | −400 | 17.6 | **13.6** |
| 2000 | −200 | 12.4 | −13.0 |
| 500 | −60 | 6.2 | −38.5 |

**段1 全程只给 1~14 m/s²，而 a_net 是 47~66** ⇒ 段1 实际是**滑行**，不是制动，
全靠段2 兜底。MATLAB 闭环仿真实测基线：`dist=2853 m, vh=29.2, tilt=29°`（不达标）。

另外一个独立发现的 bug：横向 `t_lat` 被 `min(t_lat, eg_T)` 夹死，导致
`v_rad→0` 时 `a_rad = 6d/T² − 4v/T` 的位置项被压小 ⇒ 横向失去朝目标加速能力。
仿真实测 dist 从 416 m **反弹**到 2904 m。**这个 bug 已修**（去掉天花板）。

## 2. 五次尝试（全部失败）

### 尝试① 自杀点火"走廊"当**上限**（单边刹车）

```
vz_des = -sqrt(term_v² + 2·a_sui·h_gnd)
if vz < vz_des: a_v = (vz_des - vz)/tau   # 只在下冲过快时刹车
else:           a_v = max(0, ...)          # 否则不主动下冲
```

**失败**：走廊是"从该速度起、在 h 内以 a_sui 停住"的速度**上限**。
点火时 `vz_des = −992` 而实际 `vz = −656`（实际**更慢**）⇒ 判定"安全" ⇒ **不刹车**。
推力只有 0.45~0.53，横向独自对抗 ⇒ dist 反弹到 2634 m。

**关键教训**：`a_sui` 调大只会让走廊**更宽**，方向是反的 —— 这条路本身不成立。

### 尝试② 同式当**设定值**（加位置反馈）

把 `vz_des` 当设定值，加 `tau_v` 一阶跟踪。

**失败**：
- 不加单边限制时，点火帧要求"加速下冲到 −992"，`a_v = −421 m/s²`（荒谬、致命）；
- 加单边限制后退化为尝试①。

### 尝试③ 速度待增量（Apollo "velocity to be gained"）

```
v_want = rv/|rv| · min(|v|, |rv|/t_est)
a_cmd  = (v_want − v)/t_go
```

**部分成功**：`dist 2853 → 60.4 m`（大幅改善！），`vz = −2.00`，`tilt = 2.5°`。
**但失败**：在 `vz = −55.6` 处**悬停 60 秒**，
因为 `v_want` 的幅值 `|rv|/t_est` 是**线性**的，`rv→0` 时仍给出恒定下降率。

### 尝试④ 分通道 sqrt 制动剖面（设定值版）

```
vz_want = -sqrt(term_v² + 2·a_sui·h_gnd)
vh_want = r_hat · sqrt(2·a_lat_sui·dist_hz)
a_cmd   = (v_want − v)/t_go
```

**失败**：**数值发散**（alt 冲到 3×10⁷ m、NaN）。
`sqrt` 剖面在点火帧与状态严重不匹配（`vz_want=−992` vs 实际 `−656`），
过驱动后 `a_cmd` 饱和、方向失控。

### 尝试⑤ 常数减速率（线性拟合真实日志）

对真实日志 t≤26 s 线性拟合：
`vz` 斜率 **+18.56 m/s²**（残差 rms 14.6）、`vh` 斜率 **−23.76**（rms 7.5）、
`vz/vh` 比值均值 −1.137（标准差 0.150）⇒ 真实飞行≈**固定方向匀减速**。

**失败**：匀减速**不能同时满足高度与距离**。代入 T=29.4 s 的边界条件：

| 通道 | 匀减速预测 | 真实 |
|---|---|---|
| 末端高度 | 36.8 m | 36.8 m |
| 末端距离 | **−676 m**（负！） | **47 m** |

⇒ 真实剖面**不是**常数减速，拟合只是碰巧接近。

### 尝试⑥ 直接跟踪真实日志的速度剖面（查表）

以 `h_gnd` 为自变量建表（`alt → vz_ref, vh_ref`），一阶跟踪。

**失败**：真实日志里 **alt 与 dist 是耦合的**（同一条制导同时驱动两者）。
只用 alt 查表会切断耦合：MATLAB 实测在 `alt=3365` 时表给 `vh_ref=320`，
而仿真此时 `dist` 已收到 **47 m** ⇒ 律命令"以 320 m/s 冲向目标" ⇒ 冲过目标飞走。

加了 `vh_ref = min(vh_ref_alt, dist_hz/t_ref)` 距离约束后仍不发散收敛：
`t=26` 时 `vz` 由 −11 变 **+35（爬升）**。原因是
**最后的"按 a_net 归一化"步骤破坏了竖直刹车** —— `a_h` 很大时整体缩放会把
竖直分量方向带偏。

## 3. 根因总结（下一轮必须解决的）

1. **段1 的律必须有真正的"位置闭环"**。五种失败里有四种是"只闭速度"：
   纯速度律必然收敛到某个恒定速度（悬停或滑行），不会自己走到目标点。
2. **归一化/限幅不能放在最后**。`a_cmd = a_cmd/|a_cmd|·a_net` 会改变方向，
   把竖直刹车带偏。应当**分通道限幅**，竖直与横向各自独立设上限。
3. **参考轨迹必须同时匹配 alt 与 dist**，即需要完整 `r*(t)`、`v*(t)`，
   而不是单条速度表。
4. **数学上"闭位置"在这个能量水平不可行**（已两次独立核算）：
   - 四次多项式：点火态需要 `T ≥ 81.6 s`，燃料只够 ~20.8 s；
   - 二次型位置项：`t_go=21 s` 时 `6r/t_go² = 231 m/s²`，是 `a_net(47)` 的 **5 倍**。
   ⇒ 位置**不能**靠多项式项闭合，必须靠**推力方向**（把速度矢量指向目标）。

## 4. 建议的下一轮方向（未验证，仅供参考）

结合 §3，一个可能成立的结构是**"先闭位置方向、再闭速度大小"的两级律**：

```
# 一级：位置——决定"速度矢量该指向哪"（这是 Apollo 的 v_gained 思想）
r_go   = 目标 − 位置                       # 还差的位置矢量
v_go   = 使速度矢量朝 r_go 对齐的方向修正   # 不改变 |v| 的量级
v_target_dir = unit(r_go)                  # 末端位置约束由【方向】承担
# 二级：速度——在 v_target_dir 上给出该有的速率（sqrt 剖面）
|v|_target = sqrt(2·a·|r_go|)              # 制动剖面（自然 →0）
a_cmd = (v_target_dir·|v|_target − v)/tau
# 关键：分通道限幅，绝不整体归一化
a_cmd(3) = clamp(a_cmd(3), −0.5g, a_net·sin(θ_max))
a_cmd(1:2) = clamp_norm(a_cmd(1:2), 其余额度)
```

**验证判据**（必须先在 MATLAB 里满足，再改 kOS）：
- `dist` 单调下降且末端 < 50 m；
- 不出现 `vz > 0`（不爬升）；
- `|a_cmd| ≤ a_net` 且不靠整体归一化实现；
- 交班点（alt≈5 km）状态落在 G-FOLD 可行域内。
