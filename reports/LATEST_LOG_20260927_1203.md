### 为什么会变负：速度误差累积

```
轨迹期望 v_i[0] ≈ −278 m/s（恒定，P4 最优解先匀速下坠）
本机实际 vz:  −278.5 → −273.7 → −266.9 → −262.2   【在减速】
⇒ (v_i−v)[0] 从 0 涨到 −16.9
⇒ K_VEL 项 = 0.8×(−16.9) = −13.5，压过 u_i[0]=9.9
```

### 为什么本机会减速：**姿态没转到指令角度**

物理核对（用**实际倾角**算推力分量）：

| t | tilt_cmd | **tilt_act** | thr | 用 tilt_act 算的净竖直加速 |
|---|---|---|---|---|
| 4.50 | 71.40 | **22.72** | 0.90 | +30.7 m/s² |
| 4.65 | 76.11 | **24.59** | 0.91 | +30.6 |
| 4.79 | 78.17 | **25.15** | 0.56 | +14.9 |
| 4.93 | 77.63 | **24.60** | 0.22 | −0.0 |

**`tilt_cmd`=72~78° 而 `tilt_act`=23~25° —— 差约 50°。**
指令要求推力偏向水平（竖直分量只 9.5），实际却推在 25°（竖直分量 ~40）
⇒ 竖直方向猛减速 ⇒ 速度误差累积 ⇒ 指令变负 ⇒ 水平清零。

**与实测 `vz` 变化率吻合**（预测 +30.7 m/s² 对应实测每 0.15 s 减速 4.8 m/s）。

## 3. 一个被日志掩盖的事实：`tilt_cmd` ≠ 姿态目标

```python
# line 1179  姿态追这个：
self.target_direction = target_a_ / |target_a_|      # 前瞻向量
# line 1181  日志记这个：
self.tilt_cmd = atan2(|target_a[1:3]|, target_a[0])  # 节流向量
```

**两者是不同的向量**，倾角也不同。日志里反复出现 `tilt_cmd=0` 而 `tilt_act=15~20°`：

| t | tilt_cmd | tilt_act | 说明 |
|---|---|---|---|
| 2.11 | **0.00** | 15.25 | cmd 说竖直，实际倾 15° |
| 4.21 | **0.00** | 19.81 | cmd 说竖直，实际倾 20° |
| 6.26 | **0.00** | 2.55 | 这次接近竖直 |

**⇒ 只看 `tilt_cmd` 会误判为"姿态没跟上指令"**，
实际可能是 `tilt_cmd` 根本没反映姿态目标。

### 已做的改动：新增 `tilt_dir_cmd` 日志列

```python
self.tilt_dir_cmd = degrees(acos(target_direction[0]))
```
把**真正的姿态目标倾角**记进日志，与 `tilt_act` 对比才能判断姿态好坏。
