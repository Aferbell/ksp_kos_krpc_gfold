**P1 的物理依据**（重要，别忘）：
```
av_up = g0 - d(vz)/dt
  匀速下降   => av_up = g0      => 姿态权限满
  加速下降   => av_up < g0      => 权限不足
总下降量守恒：∫(g0-av_up)dt = |vz0|  <- "权限亏欠"总量被入场速度定死
⇒ 唯一改善办法 = 不要把亏欠堆在早期
```
**注意**：用户原话是"油门顶在下限"，但**实测不是**（贴合帧 0%）——
真正机理如上；求解器那个 0.1 下限对推力幅值是**空约束**。

## 5. ★当前最重要的事：落点精度回归

### 5.1 现象

```
新三趟（AIM=500）   land_dist = 19.31 / 4.09 / 31.68 m
改动前（AIM=1000）  land_dist =  1.46 / 3.22 / 4.92 / 6.12 m
```

### 5.2 已知的机理与归因

- **机理**：位置先到目标、横速未消、冲过去。
  `213600`：`t=11.50 dist=0.84 但 vh=13.25` → `t=12.81 dist=18.49` → 落地 19.31 m。
- **归因**：`corr(land_dist, alt@gate) = −0.685`，而
  `corr(land_dist, vh@gate) = −0.038`
  ⇒ **是交班高度（AIM_ALT 让可用时间减半），不是入场横速**。
- **但证据强度有限**（只 3 新 + 4 旧；`vh<16` 分组里新批次仅 1 趟；
  离线 A/B 中 `AIM=1000` 并非每趟都更准）。
  ⇒ **记为"强相关 + 有机理支撑"，不是已证因果。**

### 5.3 建议

| 优先级 | 动作 |
|---|---|
| **1** | **决定 `AIM_ALT`**：回调到 **700**（折中）或 1000。**必须 kRPC+kOS 同步改** |
| 2 | 修 `vdesc` 日志列（现在记的是常量 80，不是实际 `vc`，导致 S2 无法从日志核对） |
| 3 | 查水平"穿越-漂回"（**既有问题**，改动前四趟同样穿越 2~4 次） |
| — | ~~P3 FIN~~ **完全达标，不要动** |

**若改 `AIM_ALT` 需知**：降 `AIM_ALT` 也让 P1/P3 更安全（时间短 ⇒ 低推力段短），
所以这是**取舍**：落点精度 ↔ 低推力段长度 + 暴露时间。
